# 🍝 Cardápio Digital - Aromi D'Italia

Bem-vindo ao repositório do cardápio digital criado para o restaurante **Aromi D'Italia**.

## 🚀 Tecnologias Utilizadas

- **React**: Biblioteca JavaScript para construção de interfaces de usuário.
- **SCSS**: Extensão do CSS para estilos mais poderosos e organizados.
- **React Router**: Ferramenta para navegação entre páginas em uma aplicação React.

## 🏗️ Arquitetura do Projeto

O projeto foi desenvolvido utilizando uma arquitetura baseada em componentes, garantindo modularidade e facilidade de manutenção.

### 📦 Componentes Principais

- **Footer**
- **Menu**
- **PaginaPadrao**
- **TagsPrato**

## 🧭 Navegação

A navegação entre as páginas é gerenciada pelo **React Router**. As páginas disponíveis são:

- **Cardapio**
- **Inicio**
- **Prato**
- **Sobre**
- **NotFound**

## 📄 Scripts Disponíveis

No diretório do projeto, você pode executar:

- `npm start`: Executa a aplicação em modo de desenvolvimento.
- `npm test`: Inicia o executor de testes no modo interativo.
- `npm run build`: Compila a aplicação para produção.
- `npm run eject`: Remove a dependência única de compilação.
